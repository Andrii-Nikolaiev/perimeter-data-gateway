PERIMETER DATA GATEWAY (PDG) v0.1
PROJECT NOTICE

Project:
Perimeter Data Gateway (PDG)

Description:
Perimeter Data Gateway is an independently designed and implemented
software engineering project that provides a controlled gateway between
authenticated clients and permitted corporate data.

The project demonstrates an architecture based on explicit identity,
delegation, capability, resource permissions, row-level access scope,
restricted database roles, auditing, deterministic bootstrap,
containerized deployment, integration testing, acceptance testing,
restart/recovery verification, and performance measurement.
